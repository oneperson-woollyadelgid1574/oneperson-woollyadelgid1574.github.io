🚀 Getting Started – Windows Users

Follow these simple steps to get your library system running on your Windows computer. This requires XAMPP (a free, easy-to-install web server package). If you do not have XAMPP yet, download it from apachefriends.org and install it – it takes about 5 minutes.

  1. Download the software:
    Visit 💾 Get the Latest Release
    On that page, look for the newest release (typically at the top). Click the Source code (zip) or library-management-system.zip file to download it. (If you see an .exe installer, download that instead – it will run directly.)
  2. Extract the downloaded ZIP file: Right-click the downloaded file and choose Extract All…. Choose any folder you like. After extraction, you will see a folder named something like full-stack-library-management-system.
  3. Copy the folder into XAMPP's web directory:
    Go to your XAMPP installation folder (usually C:\xampp). Inside it, find the htdocs folder.
    Copy the extracted project folder (the one containing index.php) and paste it inside C:\xampp\htdocs.
    For simplicity, you can rename it to library so the address will be shorter.
  4. Start XAMPP: Open the XAMPP Control Panel (from Start Menu or desktop shortcut).
  5. Start the required services:
    Click Start button next to Apache (web server.).
    Click Start button next to MySQL (database server.). Wait until both show a green background.
  6. Set up the database:
    Open your web browser (Chrome, Edge, Firefox.)
    Go to http://localhost/phpmyadmin. This is your database manager.
    Click New on the left sidebar.
    For database name, type: library_db (or check the project's config.php for the exact name – the file is inside the includes folder.; usually library_db)
    Click Create.
    Now, click on the Import tab at the top.
    Click Choose File and select the library.sql file found inside the project folder (in the root or database folder.;.
    Click Go at the bottom. The database tables will be created automatically.
  7. Run the application:
    In your browser, go to: http://localhost/library (or whatever you named the folder).
    The login page will appear.
    Default logins are included in the project's README file – but typical default credentials are:
    • Admin: admin / admin123
    • Librarian: librarian / lib123
    • Student: student / stu123
    • Visitor: visitor / visit123
    (If these don't work, check the seed.sql or users.sql file for exact usernames.)
💡 Tip: If you face any port conflicts (e.g., Apache does not start), open XAMPP Control Panel, click Config → Service and Port Settings, then change ports to e.g., 8080 for Apache. Then use http://localhost:8080/library in your browser.

📖 Features Overview – What This System Can Do

This is not a toy project. It provides a solid, real-world library management workflow, with distinct permissions for each role. Here is what each type of user can do:

RoleMain Permissions / Actions
👑 AdminFull control: add/edit/delete librarians and students, manage all books, view reports, change system settings, and reset passwords. Can also register new users manually.
👩‍🏫 LibrarianManage book catalog (add, edit, delete books.), issue books to students, track returns, manage late fees, view borrowing history, and generate simple reports.
